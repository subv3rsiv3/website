### Microsoft Under Fire for Default Security Flaws in Windows Senator Ron Wyden is calling out Microsoft for its role in enabling cyberattacks like the one on health provider Ascension, where hackers exploited a contractor's infected laptop to infiltrate the network via Bing searches. The core issue? Microsoft's default Active Directory setup still relies on outdated RC4 encryption, making it ripe for "Kerberoasting" attacks that let intruders crack admin passwords and spread malware far and wide. This vulnerability turns even strong passwords into easy targets thanks to weak hashing methods that GPUs can demolish in seconds, all because Microsoft hasn't fully phased out these insecure defaults. For SMBs and MSPs, this highlights a major headache: relying on Microsoft's out-of-the-box configs could leave your systems wide open to ransomware, potentially crippling operations without proper tweaks. And since Microsoft dragged its feet on fixes and buried warnings, small outfits might end up bearing the brunt of these preventable risks, underscoring the need for proactive security overhauls. Takeaways: - Strengthen passwords to 14+ characters to thwart cracking attempts.

        **Key takeaways**
        - Audit Active Directory for RC4 vulnerabilities immediately.
- Expect higher breach costs if defaults aren't customized.
- Push Microsoft for faster fixes to avoid ongoing exposure.
