### Microsoft Under Fire for Default Security Flaws in Windows Senator Ron Wyden has slammed Microsoft for its outdated security practices in Windows, particularly how the default setup enables "Kerberoasting" attacks that let hackers crack admin passwords. In a high-profile breach at health company Ascension, intruders started with a contractor's infected laptop via Microsoft Edge and Bing, then escalated by exploiting Active Directory's weak encryption to spread malware across the network. This vulnerability stems from Microsoft's lingering support for the ancient RC4 encryption and poor password hashing, which makes even strong passwords easy pickings for attackers using powerful GPUs. For SMBs and MSPs, this highlights a real headache: relying on Microsoft's out-of-the-box configs could leave your systems wide open to ransomware, forcing you to waste time and resources on fixes that should've been default. Worse yet, Microsoft's vague promises to phase out these risks haven't materialized, and their lack of clear warnings means small outfits are left to fend for themselves in a tech landscape that's already stacked against them. Takeaways: - Default Windows encryption invites easy password cracks.

        **Key takeaways**
        - SMBs face higher ransomware risks from unmanaged AD.
- Switch to stronger hashing to avoid GPU-based attacks.
- Long passwords alone won't cut it; enforce multi-factor auth.
