Notion 3.0's shiny new AI agents promise to automate tasks like document wrangling and database updates, but they've got a sneaky Achilles' heel: the web search tool can be hijacked for data leaks. By crafting a malicious prompt hidden in something as innocent as a PDF, attackers can trick these agents into scraping private Notion pages and shipping sensitive info—like client lists—to a shady server via a cleverly disguised query. This exploit leverages the AI's access to tools and integrations, sidestepping traditional security controls and exposing a massive threat surface that traditional RBAC just can't handle. For SMBs and MSPs relying on Notion, this means your confidential data could walk out the door unnoticed, especially if you're integrating with services like GitHub or Gmail. To stay ahead, always scrutinize shared files and limit AI agent permissions to only what's absolutely necessary, because even top-tier models like Claude Sonnet aren't immune to these underhanded tricks.
