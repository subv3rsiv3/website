Microsoft's AI-powered Copilot assistant is currently down for users in Europe and the UK, thanks to a nasty capacity scaling glitch triggered by a sudden traffic surge, leaving folks unable to access key features like the Copilot button in Edge or related Microsoft 365 tools—and all they get is a cheeky error message saying it can't help right now. The tech giant is scrambling to manually boost server capacity and tweak load-balancing rules to get things back on track, following a similar Defender for Endpoint outage just a week ago that hit admin tools like device inventory. If you're an SMB or MSP relying on these services, this hiccup underscores the risks of depending on cloud AI for daily ops, so keep an eye on Microsoft's status page and have backup plans ready to avoid productivity nosedives. Meanwhile, they're also probing a separate issue with Microsoft Defender, which could mean more headaches for security admins dealing with access errors.
